# Roadmap (порядок зависимостей, не календарь)

| # | Milestone | Эпики | Выход |
|---|---|---|---|
| M1 | Перенос ядра | EPIC-01 | ✅ ядро компилируется без Tauri, 90 тестов зелёные |
| M2 | Каркас MCP-сервера | EPIC-02 | сервер отвечает на initialize/tools списком tools |
| M3 | OAuth end-to-end | EPIC-03 | подключение BYO-приложения провайдера от браузера до токенов в Keychain (провайдер-агностично) |
| M4 | Первый синк | EPIC-04 (T-401), EPIC-06 | `sync_now` наполняет CSV WHOOP с соблюдением атомарности |
| M5 | Connector contract закреплён | EPIC-04 (T-403) | trait/checklist готовы принять второго провайдера без рефакторинга ядра |
| M6 | Закрытый MVP | EPIC-07 (T-701…T-703), EPIC-08 | плагин ставится тестерами из personal marketplace |
| M7 | Полировка дистрибуции | EPIC-07 (T-704) | MCPB-бандл с one-click установкой |
| M8 | Публичный канал (post-MVP) | EPIC-07 (T-705) | подача в директорию Anthropic |

Порядок жёсткий до M4 (каждый milestone разблокирует следующий); M6 требует M4
(минимум один работающий провайдер).

Post-MVP: Oura connector (EPIC-04 T-402, вынесен решением D-017), Garmin
ZIP-импорт (EPIC-05, вынесен решением D-018), Tauri desktop-фасад
(родительский проект), shared OAuth broker (родительский T-205), Windows-платформа
для MCPB.
